# Pedra, papel e tesoura

Projeto de console que reúne os conceitos da apostila: entrada e saída,
conversão segura de dados anuláveis, repetição, `enum`, geração aleatória e
divisão do programa em funções.

```bash
dart run
```

A partida usa o formato melhor de cinco: vence quem alcançar três vitórias
primeiro. Rodadas empatadas são repetidas e não alteram o placar.

Validação:

```bash
dart analyze
dart run test/pedra_papel_tesoura_test.dart
```
