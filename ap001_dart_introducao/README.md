# Introdução à linguagem Dart

Este diretório reúne os exemplos da apostila e as resoluções da lista de
exercícios de introdução a Dart.

## Estrutura

- `apostila/`: exemplos dos conceitos apresentados na apostila.
- `exercicios/`: resolução dos 10 exercícios da lista complementar.

Cada arquivo possui sua própria função `main` e pode ser executado
individualmente:

```bash
dart run apostila/01_hello_world.dart
dart run exercicios/ex01_decomposicao.dart
```

Para conferir todos os arquivos sem executá-los:

```bash
dart analyze .
```

Os valores de entrada estão declarados no início de cada exercício para que
possam ser alterados facilmente.
